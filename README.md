# Бортжурнал

Лётный журнал эскадрильи: вылеты, звёзды на фюзеляже, награды и приказы.

Статичный сайт без сборки: `index.html`, `style.css`, `app.js`. Данные и вход — Firebase (`cloud.js`, правила в `firestore.rules`). Без настроек Firebase сайт работает в демо-режиме и хранит всё в браузере.

Посмотреть у себя: `node tools/serve.js` и открыть http://localhost:4190.
